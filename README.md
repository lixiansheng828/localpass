## 📖 项目简介

**LocalPass** 是一款完全开源的浏览器扩展密码管理器，采用**零云端架构**。所有密码数据均在用户本地加密存储，无需注册账号，无需网络连接，从根本上杜绝了云端数据泄露的风险。

> 🔒 **核心理念**：你的密码，只有你知道。你的数据，只在你本地。

## ✨ 核心特性

### 🔐 安全加密
- **AES-256-GCM** 复杂加密算法
- **PBKDF2** 密钥派生函数（可配置迭代次数）
- 每个密码条目使用**独立盐值**
- 主密码缓存机制，避免频繁输入
- 支持**完全无主密码**的明文模式

### 💻 本地存储
- 使用 Chrome Storage API 本地存储
- **LocalStorage 双重备份**，防止数据丢失
- 无需云端账号，无需网络连接
- 数据完全由用户掌控

### 🚀 便捷使用
- **双击/连续点击**密码框快速呼出面板
- 可自定义触发点击次数和间隔
- 智能识别用户名输入框
- 一键填充，自动提交表单
- 支持多账户管理（待做）

### 📦 数据管理
- **JSON格式**导入/导出备份
- 备份文件**可选加密**保护
- 合并/替换两种导入模式（待做）
- 完整的主密码重置流程

## 🚀 快速开始

### 第一步：设置主密码
1. 点击浏览器工具栏的 LocalPass 图标
2. 在输入框中输入主密码
3. 点击"设置/解锁"按钮
4. **两次确认**主密码

### 第二步：保存密码
1. 访问任意网站的登录页面
2. 在密码框内**连续点击5次**（可自定义）
3. 在弹出的面板中点击"保存当前密码"
4. 输入标签和账号（可选）
5. 完成保存

### 第三步：填充密码
1. 在密码框连续点击5次打开面板
2. 从凭据列表中选择要填充的账号
3. 点击"填充"按钮
4. 自动完成登录

## 🔒 安全机制详解

### 加密流程
```
用户主密码
    ↓
PBKDF2 + 随机盐值
    ↓
256位AES-GCM密钥
    ↓
每个密码条目 + 独立盐值
    ↓
加密存储
```

### 主密码验证
- 存储的是加密后的验证字符串，非明文
- 验证时重新计算，不存储密码本身
- 空密码模式仍然使用加密存储（使用空字符串作为密钥）

### 密钥缓存
- 主密钥在内存中缓存5分钟
- 页面刷新/扩展重启后清除
- 修改迭代次数自动清除缓存

## ❓ 常见问题

### Q: 忘记主密码怎么办？
**A**: 主密码无法找回，只能重置扩展。重置后所有已保存的密码将丢失。**请务必定期备份！**

### Q: 为什么需要主密码？
**A**: 主密码是所有凭据的密钥，确保数据安全。可以选择空密码模式（不推荐），但强烈建议设置复杂主密码。

### Q: 如何修改主密码？
**A**: 进入设置页面，输入正确主密码，然后修改即可。

### Q: 数据存储在云端吗？
**A**: 绝不。所有数据仅存储在您的浏览器本地，使用 Chrome Storage API，不会上传任何服务器。

### Q: 如何迁移到其他浏览器？
**A**: 使用"导出备份"功能生成 JSON 文件，在其他浏览器安装 LocalPass 后导入即可。

### Q: 空密码模式安全吗？
**A**: 空密码模式下，密码仍使用 AES-256-GCM 加密（使用空字符串作为密钥），但不再需要输入密码。适合低安全性要求的场景。

### Q: 支持自动填充验证码吗？
**A**: 不支持。LocalPass 仅管理用户名和密码，验证码等动态信息仍需手动输入。
